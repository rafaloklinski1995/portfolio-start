# Portfolio Rafała

To moja pierwsza publiczna strona portfolio. Buduję ją podczas nauki HTML i CSS przez praktykę.

## Demo

[Otwórz stronę portfolio](https://rafaloklinski1995.github.io/portfolio-start/)

## Technologie

- HTML
- CSS
- GitHub Pages

## Zrealizowane elementy

- responsywny układ na komputerach i telefonach;
- menu pozostające u góry podczas przewijania;
- sekcja opisująca projekt i postępy;
- link do profilu GitHub;
- przycisk powrotu na górę strony;
- publikacja strony przez GitHub Pages.
- widoczne oznaczenie linków i rozwijanych elementów podczas nawigacji klawiaturą.

## Cel projektu

Rozwijam umiejętności tworzenia stron internetowych i buduję pierwsze elementy portfolio.
